6. 3D Mascot Asset Specifications & Code-Driven Animations

expo-image + Reanimated
✓

Phase 1 Architecture Amendment

Mascots are NOT vector SVG or Lottie. The final mascot assets are 3D-rendered-style PNG images with transparent backgrounds. In all mockups, structured placeholder boxes labeled with the pose name indicate mascot positions. In production React Native, expo-image renders the PNGs with hardware-accelerated texture caching, and idle animations (float, scale, glow pulse) are powered in code using Reanimated.
